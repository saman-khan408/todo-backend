# Todo App Backend 🚀

## 📌 About the Project

This is the backend of a Full-Stack Todo Application built using Node.js, Express.js, and MongoDB Atlas. It provides RESTful APIs to create, retrieve, update, complete, and delete todo tasks.

The application uses MongoDB Atlas to store todo data and includes search, sorting, and pagination functionality.

## 🌐 Live Deployment

**Backend API:** https://todo-backend-e88b.onrender.com/
